# PERSEE_Chaine_traitement
Chaîne de traitement des données GPS issues des colliers Catlog (acquisition toutes les 2 min), développée dans le cadre du projet PERSEE et basée sur les travaux de PERRON Rémy. Le script permet le filtrage GPS, l’identification des comportements, le calcul du taux de chargement et l’extraction d’indicateurs.
